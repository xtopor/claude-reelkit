# claude-reelkit 🎬

**Рілси й тіктоки з твоїх власних відео. Монтує Claude Code.**
Ти даєш ідею і затверджуєш сценарій. Claude пише текст, озвучує безкоштовним голосом, вибирає свіжі кадри з твого альбому, ріже їх під слова, додає ефекти руху й субтитри, зводить звук і віддає готовий MP4, обкладинку та підпис. Твого часу: близько 10 хвилин на рілс.

Працює на **Windows, Linux і macOS**. Голос — безкоштовний (Microsoft, 70+ мов, українська: Остап і Поліна). Вирізання людини для ефектів — rembg, без Apple Vision. Звукові ефекти — свій синтезований банк, без ліцензій і без CapCut.

## Що всередині

| Скіл | Що робить |
|---|---|
| 🎬 **reel-director** | Режисер. Веде рілс від ідеї до готового MP4: обирає структуру історії, вирішує, які 3–5 ефектів стануть на які такти, планує переходи та звук, а потім дивиться монтаж як критик, перш ніж показати тобі. |
| ✍️ **reel-script** | Сценарії за 4 структурами, розібраними з віральних рілсів: хук-заперечення, серія з інтригою, список факторів, «сценарій того, як…». Розбирає чужий рілс, пише твоєю мовою. |
| 🎞 **footage-scout** | Вибирає свіжі кліпи з папки, з файлів у чаті або зі спільного альбому iCloud у твоєму браузері, бере лише потрібне, робить контактні аркуші, пропускає кадри з чужими повідомленнями, номерами авто й назвами вулиць, памʼятає, що вже було. |
| ✂️ **reel-builder** | Монтажер і моушн-дизайнер: один `reel.json` → готовий MP4 1080×1920 із субтитрами, картками, ефектами, музикою, звуками і зведенням −14 LUFS. |
| 🗣 **talking-head-edit** | Для відео на камеру: чистить звук, вирізає паузи й «еее», субтитри по словах, зміна розкладок, UI-картки. |
| 🔊 **reel-capcut** | За бажанням: відправляє рілс у редаговану чернетку CapCut зі звуками з бібліотеки на кожному переході, щоб міняти музику на слух. |

**Ефекти движка** (ключі в `reel.json`, деталі в [docs/effects.md](docs/effects.md)):
обкладинка-журнал із людиною попереду · текст по орбіті навколо голови · рукописні нотатки, обведення, закреслення · скляний заголовок · стіна заголовків · чекліст · чб → колір · фотомонтаж із датою камери · наїзди на ключових словах · zoom- і whip-переходи · хук- і фінальна картки · штампи · субтитри з акцентними словами · перевірка безпечних зон Reels/TikTok.

## Встановлення

Потрібно: [Claude Code](https://claude.com/claude-code), `ffmpeg`, `node` ≥ 20, `python` ≥ 3.10.
Windows: `winget install Gyan.FFmpeg OpenJS.NodeJS.LTS Python.Python.3.12` · macOS: `brew install ffmpeg node python` · Linux: `apt install ffmpeg nodejs python3-venv`.

**Як плагін Claude Code** (рекомендовано):
```
/plugin marketplace add xtopor/claude-reelkit
/plugin install reelkit@xtopor
```
Потім один раз: `/reelkit:setup` (або `reelkit setup` у терміналі): 3–6 хвилин, ставить Python-оточення з faster-whisper, edge-tts і rembg, Chromium для Playwright, банк звуків і команду `reelkit`.

**Або вручну:**
```bash
git clone https://github.com/xtopor/claude-reelkit
cd claude-reelkit
node bin/reelkit.mjs setup
```
Перевірити будь-коли: `reelkit doctor` (або `/reelkit:doctor`).

Важкі залежності живуть окремо від папки плагіна (`%LOCALAPPDATA%\reelkit` на Windows, `~/.local/share/reelkit` інакше), тому оновлення плагіна їх не чіпають.

### Додатково (все необовʼязково)
- **Браузер** (Claude in Chrome або chrome-devtools MCP) — щоб Claude гортав твій спільний альбом у твоєму браузері. Паролі Claude не вводить ніколи.
- **ElevenLabs** — якщо хочеш їхні голоси замість безкоштовних → [docs/voice.md](docs/voice.md).
- **CapCut MCP** — лише для маршруту CapCut → [docs/capcut.md](docs/capcut.md).

## Швидкий старт

Відкрий Claude Code у папці для рілсів і скажи:

> Зроби мені рілс на 45 секунд для Instagram про те, чому люди ніколи не здають макет. Мої кліпи в папці «відео», бери тільки нові. Голос — Остап.

Режисер поставить кілька запитань, покаже сценарій на затвердження, потім збере. Або керуй движком сам:

```bash
reelkit new reels/launch                 # папка + шаблон reel.json
reelkit sheet reels/launch/src/*         # контактні аркуші, щоб вибрати моменти
reelkit tts reels/launch                 # безкоштовна озвучка зі сценарію + тайминги слів
reelkit build reels/launch --stills      # швидкий перегляд + аркуш безпечних зон
reelkit build reels/launch               # готовий MP4, cover.jpg, caption.txt у reels/launch/out/
```

## Як це працює

```
ідея ─► reel-script ─► затверджений сценарій ─► голос (reelkit tts / твій запис / ElevenLabs) ─► тайминги слів
                                                                                                   │
footage-scout ─► свіжі кліпи ─► reel.json (такти, ефекти, переходи, звуки) ◄───────────────────────┘
                                    │
reel-builder: HTML-сторінка на кожен кадр (Playwright) ─► ffmpeg ─► MP4 + обкладинка + підпис ─► критичний перегляд режисера
                                    │
                        (за бажанням) reel-capcut ─► редагована чернетка CapCut
```
Кожен кадр — HTML-сторінка, яку знімає headless Chromium, тож ефекти — це звичайні CSS/SVG/JS у `engine/template.html`. Легко розширювати.

## Приватність
Твої відео, голос і рендери лишаються на твоєму компʼютері (`.gitignore` виключає `src/`, `out/`, `frames/`). Голос генерується онлайн-сервісом Microsoft (надсилається лише текст сценарію). Нічого більше нікуди не вивантажується, якщо не користуватися маршрутом CapCut. Скіли перевіряють кліпи на чужі повідомлення, номери авто й назви вулиць, перш ніж узяти їх.
